# Future Features Roadmap

Status: **Planned — not yet started**

---

## 1. Stronger Meta-Progression & "One More Run" Hook
*Biggest missing piece*

- Add **Scrap** as a meta-currency that players keep after death
- Spend Scrap in the hub on:
  - Permanent orbital unlocks
  - Card pool expansions
  - New starting loadouts
  - "Prestige" tiers with small global buffs
- Add a visible **Scrap Counter** on the main menu
- Show a big **"+XXX this run!"** pop-up when returning to hub — players chase numbers

## 2. Deeper Build Synergies & Variety
*Make the orbital + card system feel broken in the best way*

- Create **8–10 build archetypes** (e.g. "Drone Swarm", "Melee Tank", "Status Plague", "Crit Fisher")
- Add rare **Synergy Cards** that only appear if you already have certain orbitals
  - Example: "All your fire orbitals now ignite on hit"
- Random events in the junkyard that let you **reroll or upgrade** your current build mid-run

## 3. Juicier Combat Feedback
*Survivors-likes live or die on how good it feels to kill stuff*

- Add **screen shake + camera zoom** on big kills
- Beef up **particle explosions** and **hit-stop** on charge attacks
- Add a **combo counter** or **"Overkill" multiplier** that gives bonus scrap
- Make enemy death animations more dramatic (**ragdoll + scrap explosion**)

## 4. Short, Satisfying Run Length with Clear Goals
*Make a single arena run feel complete in 12–18 minutes*

- Add **3–4 optional Bounties** per run
  - Examples: kill X of enemy type, survive wave 15 with <50% HP, etc.
  - Give bonus scrap as reward
- Show a clear **"Wave 1 → Wave 20" progress bar** so players always know they're close to an endpoint

## 5. Daily/Weekly Challenges + Leaderboards

- One **daily challenge run** with fixed starting loadout + special rules
  - Example: "No dodge roll, double scrap"
- Simple **global leaderboard** for:
  - "Most Scrap in a Single Run"
  - "Highest Wave Survived"
  - Even just top 100 creates huge FOMO

## 6. Visual & Audio Polish

- **Dynamic arena lighting** that changes with wave number (redder = harder)
- **Unique hub idle animations** for the dog bust based on current build
- Convert all **.wav → .ogg** for smaller file sizes
- Add **layered music** that gets more intense every 5 waves
